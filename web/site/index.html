seman

A semester manager that lives in your terminal.

Try it below Source on GitHub

LOADING SEMAN

Click the terminal and type, or use the keys. Your changes stay in this browser.

Features

01

Weekly dashboard

See the whole week's exams, todos and deadlines on one screen.

02

Exams with retakes

Track every exam's date, priority and retakes, grouped by subject.

03

Todos and projects

Keep quick tasks and long-running projects next to each other.

04

Keyboard only

Every action is a single key away. The mouse stays where it is.

Know what matters this week.
