seman

A semester manager that lives in your terminal. Exams, todos, projects and subjects in one weekly view, driven entirely from the keyboard.

Click the terminal and use your keyboard, or tap the keys above. On a small screen, swipe the terminal sideways to see the rest. Everything you change is saved in this browser only.

Things to try

  1. Press 4 for Todos, move with j / k and tick one off with Space.
  2. Press → to look at next week, then T to jump back to today.
  3. Press 3 and then A to add an exam. The subject field autocompletes as you type.
  4. Press 6 and then T to cycle through the eight colour themes.
  5. Press G on the dashboard to switch between this week and the whole semester.

What it does

  • Weekly dashboard. Upcoming exams, open todos and project deadlines for the week you are looking at.
  • Exams with retakes. Each exam has a date, a priority and its retake dates, grouped by subject.
  • Todos and projects. Tag them with a subject, filter by it, and add several todos at once with bulk add.
  • Keyboard only. Every action is one key, and the footer always shows the keys for the current tab.
  • Lofi player. The terminal version can play a playlist through mpv while you study. It is switched off here because a browser tab cannot start mpv.

How it is built

The app

About 4,500 lines of Go using Bubble Tea for the update loop and Lip Gloss for layout and themes. Data is one JSON file at ~/.local/share/seman/semester.json, behind a small Store interface.

This page

The demo above is not a recording or a rewrite. The same Go code is compiled to WebAssembly, drawn with xterm.js, and the Store interface is backed by localStorage instead of a file. There is no server.

Install it

With Go 1.21 or newer:

go install github.com/OmarIbrahim22/seman/cmd/seman@latest
